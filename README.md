# Trabajo práctico N°4
BBDD, SQL y Manejo de Versiones. 
El proyecto consiste en el diseño e implementación de una base de datos relacional y transaccional (OLTP) para un centro de salud en la materia Informática Médica (ITBA), con el objetivo de digitalizar la gestión de pacientes, médicos, consultas y prescripciones clínicas. La solución aborda el modelado conceptual mediante el Diagrama Entidad-Relación en notación de Chen (identificando entidades fuertes, débiles y restricciones de participación), el mapeo al modelo lógico relacional en notación Crow's Foot junto con el análisis de normalización (1FN a 4FN) y la incorporación de tablas de referencia, y la resolución de consultas SQL .
